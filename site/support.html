Support

Frequently Asked Questions

Is the app finished?

It's live on the Play Store and still actively developed — the core features documented on Features work today, and new ones roll out regularly. Expect the occasional rough edge as it keeps growing.

Is it really free? Are there ads?

Yes, completely free — no subscription, no in-app purchases, nothing gated behind a paywall. It's supported by small banner ads that never interrupt play or block a feature.

Will my data carry over as the app updates?

Yes — your campaigns live on your own device and aren't affected by app updates.

What happens if the DM's phone dies, or the app gets deleted?

The DM can export a full session backup at any time — every player's inventory, Loot, Shop, Time Keeper, and any custom item catalog — and Auto-Backup can keep one updated automatically in a folder outside the app's own storage, so it survives even a full uninstall. Restoring picks the same campaign back up as the same DM, on the same or a new device.

How do I report a bug?

Use the built-in feedback tools in the app, or reach the developer directly — see the Contact page.

Can I invite my whole group?

Please do — up to ten players can join a single game, and it's more fun (and more useful feedback for us) with the whole table involved.

Do we need internet at the table?

No cloud database, no account, no subscription — the DM's device hosts the game and everyone connects peer-to-peer. Everyone still needs some form of connection (wifi or mobile data) for those devices to actually sync with each other, though.

Why Android first?

Development resources went there first; iOS support is planned next.

Does it work with any TTRPG system?

The core features are universal, with system-specific rulesets (like D&D 5e) built in, and any other system supported through a JSON import of your own catalog — see Features and the Custom Inventory Guide for the file format.

I don't have an Android device — can I still try it?

Not yet as a native install — a browser version is in the works, and iOS is planned after that. In the meantime, a free Android emulator on your PC or Mac works fine: BlueStacks is the quickest to set up, or Android Studio's built-in emulator if you'd rather skip third-party software.
