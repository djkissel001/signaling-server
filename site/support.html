Support

Frequently Asked Questions

Is the app finished?

It's under active development — the core features documented on Features work today, and updates roll out regularly. Expect the occasional rough edge.

Will my data carry over as the app updates?

Yes — your campaigns live on your own device and aren't affected by app updates.

How do I report a bug?

Use the built-in feedback tools in the app, or reach the developer directly — see the Contact page.

Can I invite my whole group?

Please do — up to ten players can join a single game, and it's more fun (and more useful feedback for us) with the whole table involved.

Why Android first?

Development resources went there first; iOS support is planned next.

Does it work with any TTRPG system?

The core features are universal, with system-specific rulesets (like D&D 5e) built in, and any other system supported through a JSON import of your own catalog — see Features and the Custom Inventory Guide for the file format.

I don't have an Android device — can I still try it?

Not yet — a browser version is in the works, and iOS is planned after that. Android is the only supported platform for now.
